# Sources and References {#sources_page}

## Videos
* [Game Maker's Toolkit](https://www.youtube.com/watch?v=XtQMytORBmM) - Engine basics, Unity hierarchy, component architecture.
* [Tvtig](https://www.youtube.com/watch?v=T2T82MWbbew) - CharacterController setup, Input System decoupling, LateUpdate camera follow.
* [Beans](https://www.youtube.com/watch?v=NsSk58un8E0) - Video for Advanced Movement Shooter Physics. Mostly used for velocity handling and sliding.
* [Semikoder](https://www.youtube.com/watch?v=z3dequX5g_E) - CharacterController grounding and motion pipeline.
* [Dave / GameDevelopment](https://www.youtube.com/watch?v=SsckrYYxcuM) - Slope sliding vectors and normal projections.
* [Bendux](https://www.youtube.com/watch?v=K1xZ-rycYY8) - New Input System callbacks, variable jump height.
* [LlamAcademy](https://www.youtube.com/watch?v=fJyi7l2tWKo) - Raycasts, layermasks etc.
